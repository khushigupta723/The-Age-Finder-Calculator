# The age finder Calculator 🎂

A simple Age Calculator built using HTML, CSS, and JavaScript. It calculates your age based on your date of birth.

## ✨ Features
- Calculate age in years, months, and days.
- Simple and user-friendly interface.
- Instant age calculation.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
